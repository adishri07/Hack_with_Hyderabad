# Demo script (about 3 minutes)

Before recording: run `python seed_memory.py`, then click **Demo controls > Clear live activity**. Increase browser zoom to 125% and close notifications.

## 1. The problem (30 seconds)
Select **Arjun Mehta**. Turn **Memory on** off.
Ask: *How do I get access to the staging database?*
The bot confidently repeats the handbook: email IT for a shared password. Say: "This page is two years old. A normal bot has no idea."

## 2. Memory on, first joiner (40 seconds)
Select **Priya Nair**. Memory on. Point out the welcome-back note: she already finished laptop setup and VPN.
Ask: *How do I get access to the staging database?*
Ramp says the page may be outdated and forwards the question to Rahul.

## 3. The mentor answers once (30 seconds)
Select **Rahul Iyer**. Paste this answer and click **Send answer**:

> The email process is gone. Post a request in the #infra-access channel using the access template. Your team lead approves it and you're added to the stg-db-readers group. Connect with your own SSO login; there are no shared passwords.

Say: "This goes into Hindsight team memory."

## 4. Priya comes back (20 seconds)
Select **Priya Nair**. Rahul's answer is waiting for her. Click **Got it**. Her progress panel updates.

## 5. The next joiner (30 seconds)
Select **Arjun Mehta**. Memory on. Ask the same question.
He gets Rahul's answer instantly, with the source "Team memory: mentor answer". Open **Memories used** to show the recall. Say: "No mentor was interrupted."

## 6. Manager view (30 seconds)
Select **Anita Desai**. Show the stuck topics, the handbook pages to update, and click **Summarise what joiners struggle with**.
Closing line: "Every joiner makes onboarding faster for the next one."
