# Code review process
Last updated: 2026-05-20
Owner: Platform team

- Every pull request needs two approvals, and one must be from a code owner of the changed folder.
- Keep pull requests under 400 changed lines where possible.
- Post the link in the #platform-reviews channel if nobody has reviewed it within one working day.
- Reviewers use the labels "blocking" and "nit". Only "blocking" comments must be fixed before merge.
